# CachyOS + Hyprland + Caelestia Configuration

Configuración personal de mi sistema Linux basada en CachyOS, Hyprland y Caelestia.

Este repositorio sirve como respaldo completo de mi entorno de trabajo para poder reinstalar mi sistema desde cero en cualquier momento sin perder configuraciones.

---

# Objetivos

- Restaurar todo el entorno en pocos minutos.
- Mantener todas las configuraciones bajo control de versiones.
- Automatizar la instalación después de una instalación limpia.
- Tener un respaldo privado de mi sistema.
